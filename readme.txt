== Description ==
EasyChic is a modern, lightweight, and fully responsive WordPress theme designed for blogs, portfolios, and business websites.
It provides a clean and elegant design that looks beautiful on all devices from mobile phones to large desktop screens.

Key Features:
* Easy customization with WordPress Customizer
* 4 pre-built color styles to choose from
* Full Block Editor support with theme.json integration
* Fast loading with optimized assets
* Responsive design for all screen sizes
* Layout options: one-column, one-column with sidebar, or two-column with right sidebar
* Built-in breadcrumb navigation for better SEO and user experience
* Social share buttons on single posts (X, Facebook, LinkedIn)
* Custom header CTA button with color customization
* Footer widget areas (3 columns) for flexible footer layouts
* Font selection (Noto Sans JP / Noto Serif JP)
* Translation ready with Japanese language support
* Accessible design with keyboard navigation and screen reader support

== Installation ==
1. Go to "Appearance" → "Themes" in the admin panel
2. Click "Add New"
3. Enter "Easychic" in the search form
4. Install
5. Click Activate
6. Go to the Easychic menu in your admin panel

= Where can I customize the theme? =
Go to the Easychic menu in your admin panel and customize it.
You can customize various settings from Appearance → Customize in the admin panel.
